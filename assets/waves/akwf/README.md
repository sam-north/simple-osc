# Adventure Kid Waveforms (AKWF)

Single-cycle waveforms by Kristoffer Ekstrand, from
<https://github.com/KristofferKarlAxelEkstrand/AKWF-FREE>.

Released under CC0 1.0 Universal (public domain), see `LICENSE.md`. No attribution is required;
it's given anyway. These files are separate from Simple Osc's own MIT / Apache-2.0 code and don't
change its license.

Each file is one cycle: 600 samples, 16-bit mono. To add one, drop it here and append a line to
`src/waves/akwf.rs`.
